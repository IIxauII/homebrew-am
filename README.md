# IIxauII Am

## How do I install these formulae?

`brew install iixauii/am/<formula>`

Or `brew tap iixauii/am` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "iixauii/am"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
